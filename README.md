\# Superstore SQL Data Analysis



\## 📌 Project Overview



This project performs data analysis on the Superstore dataset using MySQL.



The goal is to analyze sales, profit, customers, products, regions, segments, categories, and monthly sales trends using SQL queries.



\## 🛠️ Tools \& Technologies



\- MySQL

\- MySQL Workbench

\- SQL

\- Git \& GitHub



\## 📂 Dataset



The dataset contains 9,994 records with information about:



\- Orders

\- Customers

\- Products

\- Categories

\- Sales

\- Quantity

\- Discounts

\- Profit

\- Regions

\- Segments

\- Order and shipping dates



\## 📊 Analysis Performed



\- Total sales and profit

\- Sales by category

\- Profit by category

\- Sales by sub-category

\- Profit by sub-category

\- Loss-making sub-categories

\- Sales by region

\- Profit by region

\- Sales by customer segment

\- Top 10 customers by sales

\- Top 10 products by sales

\- Top 10 products by profit

\- Loss-making products

\- Monthly sales trends



\## 📈 Key Business Insights



\- Technology generated the highest sales and profit.

\- Phones generated the highest sub-category sales: \*\*330,007.10\*\*

\- Copiers generated the highest sub-category profit: \*\*55,617.90\*\*

\- Tables had the biggest sub-category loss: \*\*-17,725.59\*\*

\- West had the highest sales: \*\*725,457.93\*\*

\- West had the highest profit: \*\*108,418.79\*\*

\- Consumer had the highest sales: \*\*1,161,401.34\*\*

\- Consumer had the highest profit: \*\*134,119.33\*\*
